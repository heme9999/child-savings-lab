# October 15 audit and local optimizations

## Findings and changes

- Valid fee inputs such as 0.004% were printed as 0.00%, making the report assumptions inaccurate. Report formatting now expands the numeric representation without reducing precision; hypothetical sub-cent money is preserved too. Calculation software version: 2026-10-15. The balance formula and policy limits have not changed.
- Tool breadcrumbs and the 404 recovery link called the comparison page “Tools.” Added a real `/tools/` directory, linked the breadcrumbs and recovery action to it, and simplified primary navigation. The directory explicitly distinguishes Trump Account tools from the five-account reading comparison; it does not promise a 529 calculator.
- Errors were only listed in the result panel, without field associations, and advanced fields could remain collapsed. Both forms now show a summary before inputs, inline descriptions, `aria-invalid`, linked field labels, and focus handling. Existing help text is retained, and editing/reset clears validation feedback. Untouched blank date inputs are no longer styled as errors.
- HTTP regression only compared page metadata, so older content with matching titles could pass. It now also compares the complete built HTML, including hashed bundle references, for public pages and genuine 404 responses.
