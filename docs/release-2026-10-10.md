# October 10, 2026 usability and calculator fixes

## Scope

- Reject contribution starts before July 4, 2026 and incomplete numeric inputs.
- Validate the central growth scenario first; omit unsupported sensitivity rates instead of leaving an old result on screen. Hide results and disable printing after edits until successful recalculation.
- Treat incomplete eligibility answers as unknown, not as a negative eligibility result. Start without a prefilled birth date or assessment, and clear the previous assessment on edits/reset.
- Preserve the homepage's fictional amount/return/no-pilot scenario in the full calculator using a strictly allowlisted URL fragment. Do not serialize user-entered birth dates or financial data.
- Include all assumptions, calculation version, and report time in the print layout. Keep advanced inputs behind a disclosure.
- Replace horizontally clipped comparison tables with labeled cards on small screens; retain semantic tables on desktop and in print.
- Add a source-linked 529 starting guide and real navigation to the other account types. Add summaries and section navigation to long guides.
- Use each article's own ISO review date for both visible text and structured metadata. Check review-date consistency, local anchors, and the new guide during build validation.

## Content boundaries

This is an independent educational publication, not licensed legal, tax, investment, payroll, or benefits advice. This release does not assert licensed-professional sign-off. Trump Account source review dates remain October 8 unless a specific record was reviewed again; the calculation version is a separate concept.

The new 529 guide uses SEC Investor.gov bulletins updated January 28, 2026 and IRS 529 guidance. Older IRS 529/ABLE examples and FINRA custodial-account figures are explicitly not presented as current limits. The FINRA material is used for ownership structure, not as federal tax authority. No provider rankings, commercial email service, custom domain purchase, account access, or Search Console changes are included.

## Verification

The full verification command covers Astro/TypeScript, 94 unit and regression tests, static output/sitemap consistency, internal links and section anchors, review dates, genuine 404 output, metadata, and HTML validation.

Local browser checks, using fictional inputs, verified:

- Homepage $200/month at 4% and the full calculator both show $58,523 with no pilot amount.
- Editing hides the prior result and disables Print report. A 20% scenario recalculates and shows only 18%/20% sensitivity rows; a -99% scenario shows only -99%/-97% rows.
- Blank annual return produces a named error; January 1, 2026 is rejected. A January 15, 2025 birth date with a July 4, 2026 start models 198 contribution month-ends and $19,800 in family deposits at $100/month.
- The assumption summary contains the entered values, 0.10% fund expense, and the calculation version.
- Blank/unknown eligibility answers produce no assessment. Complete hypothetical answers route to official account-status checking. Clearing the birth date and Reset both remove the prior assessment.
- At 390px width, all five comparison cards expose purpose, control, and key constraint with no page-level horizontal overflow. The 529 guide also has no horizontal overflow.
- No browser console errors or warnings were recorded during the local checks.

Deployment remains gated by `npm run deploy:cloudflare`, which repeats the full build checks and tests production GET/HEAD responses for every public page, sitemap/robots resource, and intentionally missing URL. The immutable deployment must separately pass the same suite with preview noindex headers. A new release is not considered successfully deployed merely because upload succeeds.
